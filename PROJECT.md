# World Build 010 — COUNTERBALANCE

## Thesis

Fair comparison begins with how groups were formed, not with which test returns a small number. Make the assignment mechanism inspectable, preserve its units and counts, and connect it to the reference distribution used in analysis.

## What is implemented

- Editable one-paragraph protocol, group names, outcome unit and bounded roster.
- Fixed-count blocked allocation using browser cryptographic words and rejection-sampled Fisher–Yates.
- Replay consistency checks on the complete consumed-word transcript, including rejected words.
- Strict local CSV and portable JSON workflows, explicit replacement confirmation and no automatic missing-row deletion.
- Block-size-weighted differences, sharp common-additive-effect tests and closed confidence intervals from exact algebraic inversion.
- Exact enumeration or a fixed-size seeded simulation bank; exact BigInt rational comparisons for both paths.
- Worker-based calculation with cancellation, operation ownership, revision guards and atomic result replacement.
- Accessible textual plot summaries, block tables, local exports, responsive layout, reduced motion and installed keyboard-capable controls.
- Optional task-completing browser tools sharing the visible state.

## Progression from earlier builds

RESONANT connected real local signal files to numerical transforms and reversible processing. COUNTERBALANCE adds a design-to-inference chain: the admissible assignments are derived from the declared study, exact decimal arithmetic determines tails, and a separately verified inversion produces interval endpoints without a search grid. Independent scientific and workflow reviews informed implementation fixes.

## Design system

Light field-notebook workspace; cobalt A and rust B with explicit text labels, serif editorial headings and monospaced protocol metadata. The allocation diagram, distribution and exact block decomposition carry the interface. No stock imagery, fabricated research outcomes or marketing dashboard.

## Boundaries

Not a preregistration service, assignment-concealment system, clinical-trial platform, missing-data method, clustered-outcome analyzer, power calculator, multiple-testing correction or generic causal inference engine. No third-party study-data transmission, permanent storage or new spending. Imported design claims are unverified.

## Validation and publishing

See TESTING.md for verified checks and explicit exclusions. A functional release is published only after the local workflow, browser-tool contract, build and release scan pass. Public source excludes private hosting identifiers before its first public commit. Private hosting receipts remain local and ignored.

## Useful next extensions

Only after this bounded release is stable: independently validated heterogeneous-effect intervals; an explicit cluster-randomization design; accessible row-by-row data entry; an immutable external preregistration integration. Each requires a separate methodological and privacy review rather than a cosmetic label change.
